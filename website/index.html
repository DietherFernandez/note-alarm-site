Three ways to be reminded

Pick the alarm that fits the moment.

Every reminder chooses its own ring mode. Change it per note — there is no global setting to wrestle with.

Mode A

Sound only

Your chime, the system alarm sound, or an audio file you imported. It plays and keeps ringing until you snooze or dismiss.

Chime · loops until dismissed

Mode B

Voice only

The phone reads the note aloud — title, content, or both — and repeats the announcement at your chosen interval.

“Morning stand-up. Ship the release notes…”

Mode C

Sound + voice

The alarm keeps playing while the note is spoken. Speech ducks the chime — it never mutes it.

Voices come from Android's text-to-speech engine, including the ones already installed on your phone. If a chosen voice isn't available, NoteAlarm says so and falls back to the alarm sound — it never fails silently.

What's inside

Small app. Serious about the basics.

Built like a tool you own, not a service you rent.

Fully offline

No internet permission, no account, no cloud. Notes, reminders and preferences live in a local database on the device.

Exact timing

Built on Android's exact-alarm APIs, so a 9:00 reminder rings at 9:00. The app explains the permission if the system asks for it.

Sounds you choose

Built-in tones, the system alarm sound, or an audio file you import — copied onto the phone, not streamed from anywhere.

Act from the notification

Snooze for five minutes or dismiss without opening the app. The notification stays put while the alarm rings.

Notes that keep up

Search, pin, undo a delete, and see word and character counts while you type. The list sorts the way you expect.

Privacy controls

Hide note text on the lock screen if you want, and choose separately whether the voice reads the title, the content, or both.

Questions, answered plainly

How do I get the app?

Send a trial request by email. I reply personally with the APK and its SHA-256 — there is no public download page.

Does NoteAlarm need internet?

No. The app does not request the internet permission at all. Notes, reminders and settings stay in a local database on the phone.

Will the voice speak in my language?

It uses the text-to-speech voices installed on your device. Pick a language and a voice in the note's voice settings. If the chosen voice is missing, the app warns you and falls back to the alarm sound.

Why does Android mention exact alarms?

Android can delay inexact alarms to save battery. NoteAlarm uses the exact-alarm APIs so a 9:00 reminder actually rings at 9:00. Settings shows whether the permission is allowed.

Is there a cloud backup?

No. There is no account and no cloud copy. The notes live in the app's local storage; uninstalling the app removes them.

Which Android versions are supported?

Android 8.0 (API 26) and newer. It has been tested on a Samsung Galaxy A06 running Android 16.
